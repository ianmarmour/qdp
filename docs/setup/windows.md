# Installing on Windows

The installer adds the Quick Desktop app, and the `qdp` command for sharing
this PC.

## Requirements

- Windows 10 or later on x86-64

## Install

Download and run
[`qdp-windows-x64.msi`](https://github.com/ianmarmour/qdp/releases/latest/download/qdp-windows-x64.msi). It needs nothing else
installed first.

## Upgrade and remove

Run a newer installer to upgrade. To remove Quick Desktop and the command,
use Settings, Apps.
