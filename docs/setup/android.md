# Installing on Android

## Requirements

- Android 10 or later on 64-bit ARM

## Install

On the device, download [`qdp-android-arm64.apk`](https://github.com/ianmarmour/qdp/releases/latest/download/qdp-android-arm64.apk)
and open it. Android asks you to allow installing apps from your browser or
file manager; allow it, then install.

## Upgrade and remove

Install a newer APK over the old one to upgrade; if Android refuses, uninstall
the app first. To remove Quick Desktop, uninstall it as any other app.
